# 大模型代码边界防御能力评测与数据合成闭环

## 1. 项目背景
本项目旨在复现 AI 数据工程的闭环：发现模型缺陷 -> 构建评测集 -> 引入 Grader 打分 -> 定向数据合成干预 -> 对照实验验证。

## 2. 实验设计与数据
- **基座模型**：Qwen2.5-7B (Ollama 本地部署)
- **评测集**：手工构建 10 道针对空值、异常类型的边界代码题。
- **裁判模型 (Grader)**：从 0.5B (发现严重幻觉) 升级为 7B，并引入严苛判分 Prompt 完成可靠性校准。
- **数据干预**：合成 3 条防御性极强的代码作为 Few-Shot 范例进行上下文注入。

## 3. 核心实验结果
| 实验阶段 | 平均防御得分 (满分5分) | 提升幅度 |
| :--- | :--- | :--- |
| 基线测试 (无干预) | 1.50 | - |
| Few-Shot 数据干预 | 3.80 | **+153%** |

**结论**：高质量的定向合成数据能显著修补模型在特定维度（如边界防御）的短板。

## 4. 个人反思（重点）
- 轻量级模型做 Judge 易产生“自相矛盾”的幻觉，必须进行校准。
- 评测指标不能只看整体分数，要分析 3 分题（尝试防御但漏了类型检查）背后的归因，这为下一步的数据合成指明了方向。
